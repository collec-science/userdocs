Le fichier **.env**, positionné à la racine de l'application, permet de définir les paramètres généraux de fonctionnement de l'instance, et notamment le mode d'identification choisi.

Collec-Science est développé à partir du *framework* CodeIgniter, qui est complété par un  module complémentaire qui s'occupe de la gestion de l'interface, de l'identification, de la sécurité, etc. PPCI (*PrototypePhp for CodeIgniter*). La documentation complète de ce module est disponible ici : https://equinton.github.io/ppcidocs/fr/index.html.

Les paramètres utilisables dans le fichier .env sont décrits à partir de cette documentation : https://equinton.github.io/ppcidocs/fr/parameters.html
