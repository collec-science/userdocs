Le logiciel fait l'objet de mises à jour régulières, soit pour corriger des défauts (bugs), soit pour rajouter des nouvelles fonctionnalités.

Le code source de l'application est stocké sur le site https://github.com/collec-science/collec-science, qui fonctionne avec la technologie de gestion de code GIT. Les nouvelles versions sont déclarées dans ce dépôt, et peuvent être visualisées à partir de ce lien : https://github.com/collec-science/collec-science/releases.

Vous pouvez consulter la dernière version publiée soit directement depuis le lien précédent, soit depuis l'application, en choisissant, dans le menu, *? > Nouvelle version ?* : le logiciel affichera la version courante de votre instance Collec-Science, et vous informera si une nouvelle version a été publiée ou non, avec la liste (en anglais) des modifications apportées.

## Consulter les nouveautés

Les principales évolutions du logiciel sont décrites à différents endroits. Vous les retrouverez d'une part depuis la liste des versions sur le site https://github.com/collec-science/collec-science/releases (en anglais), mais également dans le logiciel.

Pour cela, depuis le menu, choisissez *? > Nouveautés*. La liste, en français (ou en anglais, si vous avez sélectionné cette langue) sera affichée.

Pour chaque version, vous retrouverez la liste des corrections de bugs et la liste des nouveautés apportées.
