Une liste complète des pays et territoires est fournie lors de l'installation du logiciel. Cette liste reprend la codification officielle, avec :

- un identifiant numérique
- un code alphabétique sur deux chiffres, en majuscules
- un code alphabétique sur trois chiffres, en majuscules
- le nom du pays ou du territoire.

Il est possible de mettre à jour cette liste en anglais, le logiciel contenant deux listes des pays (sans les territoires) pré-chargées en anglais et en français. Cette fonctionnalité est néanmoins réservée aux utilisateurs disposant du droit *param* (*cf.* [[Les différents types de droits]]).

Pour cela, positionnez-vous dans *Paramètres > Liste des pays*.  Sous la liste, vous disposerez d'un formulaire :

![[Pasted image 20260711162659.png]]

Les deux premiers choix permettent d'utiliser les listes pré-chargées dans le logiciel. Ces listes ont été récupérées depuis le site [https://stefangabos.github.io/world_countries](https://stefangabos.github.io/world_countries).

Si vous choisissez la troisième proposition, vous pourrez alors sélectionner le fichier à importer. Sa structure doit correspondre à celle fournie par le site https://stefangabos.github.io/world_countries. 

Les codes alphabétiques seront transformés en majuscules lors de l'importation.
